# Playlist Maker

Playlist Maker — учебное Android-приложение для поиска музыкальных треков, просмотра деталей трека, добавления треков в избранное и работы с плейлистами

## Возможности

- главный экран с переходами к поиску, плейлистам, избранному и настройкам;
- поиск треков через репозиторий и сетевой клиент;
- экран деталей трека с обложкой, длительностью, избранным и добавлением в плейлист;
- создание плейлистов с названием, описанием и обложкой;
- просмотр списка плейлистов и экрана деталей плейлиста;
- удаление плейлиста с экрана плейлиста по иконке корзины;
- удаление плейлиста из списка по долгому нажатию;
- диалог подтверждения перед удалением плейлиста;
- экран избранных треков с удалением по долгому нажатию;
- хранение данных через Room и истории поиска через DataStore.

## Сборка и запуск

1. Установите Android Studio и Android SDK.
2. Клонируйте репозиторий и откройте проект в Android Studio.
3. Дождитесь Gradle Sync.
4. Выберите эмулятор или подключенное Android-устройство.
5. Запустите конфигурацию `app` из Android Studio.

Для проверки через терминал:

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
.\gradlew.bat installDebug
```

Точка входа приложения: `com.example.playlist_maker_android_rogachevegor_.ui.activity.MainActivity`.
