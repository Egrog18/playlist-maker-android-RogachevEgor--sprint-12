# Чек-лист самопроверки Playlist Maker, спринт 12

## Общая проверка

- [x] Проект компилируется без ошибок.
- [x] Приложение запускается без ошибок.
- [x] При запуске открывается главный экран.
- [x] Навигация между экранами работает стабильно, приложение не падает.
- [x] Навигация задается в классе `PlaylistHost`.

## Главный экран, спринт 3

- [x] На главном экране есть кнопки для перехода к поиску, плейлистам и настройкам.
- [x] На главном экране есть кнопка для перехода в избранное.
- [x] При нажатии на кнопки выполняются переходы на соответствующие экраны.
- [x] В манифесте прописаны `MainActivity` и `AllTracksActivity`.

## Экран поиска, спринты 4-6

- [x] В строке поиска отображается placeholder «Поиск».
- [x] Есть иконка «Лупа» слева и иконка «Очистить» справа.
- [x] При вводе текста можно очистить строку нажатием на «х».
- [x] При нажатии на «Лупу» запускается поиск.
- [x] Пока поиск идет, показывается индикатор загрузки.
- [x] Если поиск завершен успешно, отображается список треков.
- [x] Если произошла ошибка, показывается сообщение об ошибке.
- [x] Отображается длительность трека в формате `mm:ss`.
- [x] Список треков сверстан с помощью `LazyColumn`, элементы списка кликабельны.

## Экран настроек, спринт 4

- [x] Есть кнопки «Поделиться приложением», «Написать разработчикам», «Пользовательское соглашение».
- [x] Нажатие «Поделиться приложением» открывает системное окно выбора приложения.
- [x] Нажатие «Написать разработчикам» открывает почтовый клиент с заполненными адресом, темой и телом письма.
- [x] Нажатие «Пользовательское соглашение» открывает браузер со ссылкой.
- [x] Строки вынесены в `strings.xml`.

## Экран поиска. Архитектура, спринты 5-6

- [x] Архитектура разделена на `Data` / `Domain` / `UI`.
- [x] Пункт про эмулятор сервера `Storage` не применяется в актуальной версии проекта: поиск работает через `NetworkClient` и репозиторий.
- [x] Реализован репозиторий `TracksRepositoryImpl`, возвращающий список треков.
- [x] В `Domain` есть интерфейс `TracksRepository`, в `Data` есть `NetworkClient`.
- [x] `SearchViewModel` управляет состояниями `Initial`, `Searching`, `Success`, `Fail`.
- [x] `SearchScreen` корректно отображает состояния поиска.

## FloatingActionButton и BottomSheet, спринт 7

- [x] Экран создания плейлиста позволяет сохранить результат.
- [x] После сохранения новый плейлист появляется в списке.

## Экран плейлиста, спринт 9
